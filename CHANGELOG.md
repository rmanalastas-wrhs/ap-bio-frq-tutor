# Changelog

All notable changes to the AP Biology FRQ Tutor are documented here.

---

## July 31, 2026

### Added
- Response history workflow
- Revision stages (Initial Response, Revision 1, Revision 2)
- Progress indicator
- Question Complete workflow
- Printable response history

### Changed
- One question is now generated for each selected task verb.
- Multiple task verbs are displayed as (a), (b), (c).
- Feedback headings now correspond to each response stage.
- Revision prompts now preserve previous student responses.

### Fixed
- CORS errors between GitHub Pages and Google Apps Script.
- Deprecated Gemini model updated.
- GitHub deployment issues resolved.
- Google Apps Script deployment updated.
- Question generation now produces one question per selected task verb.

### Known Issues
- Gemini API free-tier quota (429) limits testing.
- Need to complete Test B (three unsuccessful submissions).
